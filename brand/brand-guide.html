A Free Gemini API não é um produto de consumo. É uma ferramenta que um dev encontra às 2 da manhã, entende em 30 segundos e coloca em produção. A identidade tem que fazer exatamente isso: provar competência técnica antes de pedir atenção.

01 · Conceito da marca

O símbolo é o próprio fluxo da API

Dois chevrons espelhados formam um losango partido ao meio. É a estrutura literal do projeto: o cliente entra pela esquerda, o Gemini responde pela direita, e a API é o ponto no centro, o único lugar onde o payload existe.

‹  chevron azul

O request. Azul porque é a parte que você controla: o cliente, o token, o prompt.

›  chevron branco

A resposta do Gemini. Neutra, porque é matéria-prima externa: a API não a inventa, só encaminha.

●  ponto central

A sessão. O JWT, os cookies, o snapshot, tudo que a API guarda enquanto a conversa acontece.

O vão entre os dois chevrons é intencional: eles nunca se tocam. A API é a lacuna, não a ponte desenhada por cima dela.

Não faça

✕Não feche o vão entre os chevrons. O vão é o conceito.
✕Não rotacione, incline ou reflita a marca.
✕Não use as cores oficiais do Google/Gemini. Este é um projeto independente.
03 · Cor

90% neutro, 10% sinal

O azul não é decoração, é semântica. Ele marca só o que é acionável ou é o request. Se tudo brilha, nada informa. Clique em qualquer swatch para copiar o hex.

Neutros · a base

Texto secundário

Sinal · use com parcimônia

Regra 90/10 · em qualquer tela, no máximo 10% da área pode ser accent ou cor de status. As quatro cores de sinal mapeiam 1:1 nos códigos de erro documentados em doc/ERROR_CODES.md: o usuário aprende a paleta lendo os logs.

04 · Tipografia

Inter fala, JetBrains Mono prova

Duas famílias, papéis rígidos. Inter para prosa e interface. JetBrains Mono para tudo que uma máquina produziria: endpoints, códigos de erro, hex, chaves de env, labels de seção. Nunca use mono como corpo de texto, porque vira estética vazia.

06 · Tom de voz

Escreva como quem já debugou isso

O README atual já acerta o tom: ele diz abertamente que "qualquer framework Node moderno seria adequado" e lista o que o projeto não faz. Essa honestidade é o maior ativo da marca, porque sinaliza senioridade melhor que qualquer adjetivo.

PrincípioDigaNão diga
Específico, não superlativo "Resposta em ~1.8s; o gargalo é o Gemini." "Performance ultrarrápida e escalável."
Limites na frente "Não mantém histórico entre chamadas." Omitir e deixar o dev descobrir em produção.
Erro como instrução "Sessão expirada. Crie uma nova em POST /create-session." "Ops! Algo deu errado 😅"
Mostre, não prometa Um bloco de cURL que roda copiando e colando. "Integração simples e intuitiva."
Sem hype de IA "Proxy HTTP fino para o Gemini web." "Plataforma de IA revolucionária."
