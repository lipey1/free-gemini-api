Gemini over REST · no SDK · no browser · no cost

Most of this page
is Google's latency.

Free Gemini API is a thin HTTP proxy. It replays the StreamGenerate request your browser would make on gemini.google.com, parses the stream, and hands you back plain JSON. Node 18 and Elysia — no Puppeteer, no headless Chrome, no official SDK in the hot path.

Where the time actually goes

This is the honest shape of a /chat call. Everything this project wrote — JWT check, SQLite read, prompt injection, stream parsing — adds up to roughly 21ms. The remaining 1.79s is Google answering. Choosing Elysia over Express moves the blue bars, not the striped one.

Numbers are an observed order of magnitude from local runs against the live instance — not a published benchmark, and there is no load-test suite behind them. Treat them as shape, not as a guarantee.

4endpoints
Surface area

Four endpoints. That is all of it.

POST/create-session

Fires one cookieless StreamGenerate, keeps whatever Set-Cookie comes back, stores the snapshot in SQLite, returns a signed JWT.

~680 ms · 1 req / 15 s per IP
{ "ok": true,
  "sessionToken": "eyJhbGciOiJIUzI1NiIs…",
  "expiresInSeconds": 2700 }
POST/chat

Takes a prompt, substitutes it into the captured f.req body, forwards it with the session's cookies, returns the parsed text. Token goes in the header or the body.

~1.84 s · 30 req / min per IP · max 20 000 chars
{ "ok": true,
  "reply": "A stream is an abstraction for…" }
GETPOST/session/status

Checks the token against the store without calling Google. Always HTTP 200 — an expired session is an answer, not a protocol error.

<5 ms · 60 req / min per IP
{ "ok": true, "valid": false,
  "reason": "token_expired",
  "expiredAt": "2026-06-15T13:00:00.000Z" }
GET/docs·/openapi.json

Swagger UI plus a static OpenAPI 3.0 spec. Authorize with the session token and run the calls straight from the browser.

Budgets

Limits, stated up front

Per-IP fixed windows held in memory. Every one of them is an env var, and 0 turns that limit off. When a session's 45 minutes run out, /chat answers SESSION_EXPIRED and you create a new one.

What this project does not do

These spans have no duration because the work never happens. Better you read it here than discover it in production.

browser.launch · puppeteer
no headless Chrome anywhere in the stack
files.upload
text prompts only — no images, no attachments
history.append
no conversation memory between /chat calls
cookies.auto_refresh
template in src/config/gemini.js is updated by hand
genai.official_sdk
@google/genai is not in the hot path
notescope

Read this before you depend on it

  • 01Independent study project. Not affiliated with, endorsed by, or connected to Google.
  • 02It talks to an internal endpoint of gemini.google.com, not a public documented API. When Google changes that protocol, this breaks until the template is updated by hand.
  • 03No uptime target, no test suite, no support commitment. Built to learn how the protocol works and to be read as source.
  • 04For anything production-critical, use Google's official API. That is what it is for.
